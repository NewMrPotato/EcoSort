# Исследование для EcoSort

Проект начался с вопроса о том, как помочь жителям разобраться в правилах сортировки отходов и найти подходящий пункт приёма.

Анкету распространяли через городские чаты. В опросе участвовали 172 человека.

| Показатель | Доля опрошенных |
| --- | ---: |
| Считали, что низкая осведомлённость мешает внедрить раздельный сбор в городе | 80% |
| Считали, что мобильное приложение поможет повысить осведомлённость о раздельной утилизации | 89% |

Проценты приведены по итоговым материалам проекта. Опрос проводился среди добровольцев, поэтому результаты описывают ответы участников и не показывают, насколько изменилось их поведение после использования приложения.

В прототипе отразили две задачи. Уроки объясняют, как сортировать отходы, а карта помогает понять, где можно сдать вторсырьё.
