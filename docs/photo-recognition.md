# Распознавание отходов

EcoSort анализирует одно изображение локально на CPU. Сфотографируйте один предмет или выберите готовый снимок. Модель предлагает категорию для всего изображения.

## Выбор модели

| Кандидат | Артефакт | Решение |
| --- | --- | --- |
| MobileNetV2 из Waste-Classification-using-mobilenet | FP16 TFLite, 5 192 428 байт, MIT | Выбран готовый файл с кодом подготовки данных и фиксированным порядком десяти классов |
| MobileNetV2 из SSHAOCC/GarbageClassifier | TFLite, 9 518 668 байт | В README заявлена MIT, отдельного файла лицензии в проверенном снимке нет |
| Stefaron/trash-classifier | ResNet50, Keras, вход 384 × 384, MIT | Для Android потребуются конвертация и дополнительная проверка |

Источники кандидатов — [MobileNetV2](https://github.com/nirajshevade/Waste-Classification-using-mobilenet), [GarbageClassifier](https://github.com/SSHAOCC/GarbageClassifier), [ResNet50](https://huggingface.co/Stefaron/trash-classifier).

Выбранный артефакт зафиксирован на коммите `d6793018602abe9d86e61e6e55f047ed181b4698`. Его SHA-256 — `80a3fc010bd0de1c376cdabab2bfc7630210b28c15df738997a009d8891cd492`. Модель и исходный текст MIT включены в `app/src/main/assets/models/`. Машиночитаемые сведения находятся в `waste_model.json`.

Модель различает батарейки, органические отходы, картон, одежду, стекло, металл, бумагу, пластик, обувь и прочие отходы. Метки перечислены в `waste_labels.txt`. При загрузке приложение проверяет их порядок и размерности тензоров.

## Подготовка изображения

Приложение копирует выбранный снимок в собственный кеш. Ограничение файла составляет 20 МиБ. Изображение уменьшается до 1024 пикселей по длинной стороне с учётом поворота и отражения EXIF. Для модели применяется билинейное масштабирование до 224 × 224, RGB и преобразование каждого канала `value / 127.5 - 1`. Тип входа и выхода — float32, веса хранятся в FP16.

Используется встроенный LiteRT 1.4.2 с Interpreter API для совместимости с Android API 21. Модель запускается в одном фоновом потоке с двумя вычислительными потоками. Загрузка модели, чтение снимка и анализ выполняются вне UI-потока. Состояние сохраняет ViewModel, путь к локальному снимку сохраняется для восстановления процесса.

## Проверка

Проверочный прогон использовал первые десять файлов каждой из шести категорий TrashNet в лексикографическом порядке.

| Категория | Совпадения |
| --- | ---: |
| Картон | 10 из 10 |
| Стекло | 9 из 10 |
| Металл | 10 из 10 |
| Бумага | 7 из 10 |
| Пластик | 8 из 10 |
| Прочие отходы | 9 из 10 |
| Всего | 53 из 60 |

Прогон проверяет подготовку изображения и вывод модели. Пересечение с обучающими данными исключено не было, поэтому показатель нельзя считать качеством на независимой выборке. Четыре дополнительные категории этим прогоном не проверялись.

Полный [отчёт прогона](recognition-smoke-results.json) содержит пути всех 60 изображений, предсказания, оценки и контрольные суммы модели и архива. Время в отчёте измерено на настольном CPU.

Для повторения нужны Python 3.11, `ai-edge-litert==2.4.0`, NumPy и Pillow. Архив находится в [репозитории TrashNet](https://github.com/garythung/trashnet/blob/6fa2b878c6c1b4304b91109070ce0edf9279bb31/data/dataset-resized.zip).

```text
python tools/evaluate_waste_model.py --trashnet path/to/dataset-resized.zip --output smoke-results.json
```

Android-тесты используют шесть корректно распознаваемых примеров из этого прогона для проверки нативного runtime. Имена файлов и происхождение указаны в `app/src/androidTest/assets/waste/fixtures.json`, лицензия TrashNet сохранена рядом. Эти примеры проверяют интеграцию. Отдельно проверяются EXIF, уменьшение больших изображений, пустое и повреждённое фото, неуверенные оценки и пересоздание экрана.

Проверка на эмуляторе Android API 36.1 прошла с отключёнными Wi-Fi и мобильными данными. Через интерфейс проверены выбор снимка в Photo Picker, съёмка камерой, автоматический анализ, отмена выбора с сохранением предыдущего результата и восстановление задачи из списка недавних приложений после завершения процесса. Девять локальных и семь Android-тестов завершились успешно. Debug- и release-сборки, Android Lint проходят; в существующих экранах и зависимостях остаются предупреждения Lint.

## Ограничения результата

Модель распределяет оценки между десятью известными категориями. Неизвестные предметы, несколько объектов и сложный фон могут привести к ошибке даже при высокой оценке.

Категория показывается с формулировкой «Похоже на». При максимальной оценке ниже 0,7 или разнице между первыми двумя вариантами ниже 0,2 приложение показывает неуверенный результат. Пороги выбраны как эвристика интерфейса, их надёжность на новых фотографиях не откалибрована. Почти однотонный снимок отклоняется по низкой вариации яркости.

По фото нельзя надёжно установить маркировку полимера, опасность содержимого или правила переработки в конкретном городе. Подсказки требуют проверки материала и местных условий приёма.
