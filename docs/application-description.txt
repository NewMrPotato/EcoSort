EcoSort — мобильное приложение для изучения правил раздельного сбора отходов, распознавания мусора по фотографии и поиска пунктов приёма вторсырья.

В разделе обучения доступны шесть иллюстрированных материалов: причины сортировки, основные виды отходов, разновидности пластика, назначение контейнеров, правила раздельного сбора и факты о переработке.

Для распознавания пользователь делает снимок или выбирает фотографию из галереи. Приложение предлагает три наиболее вероятные категории с оценками модели. Поддерживаются бумага, картон, пластик, стекло, металл, батарейки, органические отходы, одежда, обувь и прочие отходы. При уверенном результате отображается подсказка по сортировке, при неуверенном — рекомендация изменить ракурс или фон. Обработка выполняется на телефоне без подключения к интернету.

Каталог позволяет искать пункты приёма по названию и адресу, просматривать записи списком и переходить к их расположению на карте. В демонстрационной версии представлены 24 пункта Нижневартовска. Список и поиск доступны без интернета.

Результат распознавания носит справочный характер: маркировку материала, актуальность адресов и условия приёма необходимо уточнять отдельно.
